> **Test-database safety guard (S-6, not a placeholder).** `tests/TestCase.php::guardTestDatabase()` throws before any migration unless the resolved connection name contains `test` (or is `:memory:`). Because `RefreshDatabase` wipes whatever connection it runs against, this makes a misconfigured `DB_DATABASE=novel_engine` abort the suite instead of destroying dev/prod data. `phpunit.xml` already pins `DB_DATABASE=novel_engine_test`; the guard is the fail-closed backstop.
