# S-5.1.1 — Player moment input Test Plan

> **Feature:** [../features/session/S-5.1.1-player-input.md](../features/session/S-5.1.1-player-input.md) · **Last Updated:** 2026-06-08

## Scope

Covers committing the player's contribution at a player moment: the input is appended to the `events` scene log, the turn is handed back to the narrator (`player_moment → narrator_turn`, same beat), acting off-turn is rejected with the save unchanged, `content` is required + bounded, and the two writes are **atomic** (a failed scene-log write rolls the whole moment back). Not covered: prose/handoff generation (S-4.2.1/S-4.2.2), the bounded immediate-context window + scene summary (S-5.2.1 remainder), the resume anchor (S-5.3.1), the Play reader's visual rendering (S-5.4.1 — exercised via prop assertions only).

## Preconditions / fixtures

A `PlaySession` owned by the acting user, parked on a chosen `state_node` (`player_moment` / `narrator_turn` / `beat_complete`) and positioned at an authored beat. `sceneSave()` builds a story with one chapter/scene/beat + one character; `twoBeatSave()` adds a second ordered beat for the continue path. Auth via `actingAs`; the atomicity case mocks `SceneLogService` in the container to throw.

## Regression

`SessionStateMachineTest`, `SessionForkTest`, and `SessionSaveManagementTest` must stay green — `SessionService` gained `SessionStateMachine` + `SceneLogService` dependencies and a new method, but the existing lifecycle methods are unchanged. `NarratorTurnTest` (the narrator half of the loop) is unaffected.

## Safety assertions (if applicable)

- [x] No agent prompt is assembled and no `true_state` / hidden fact is read — the input is recorded verbatim (no leak surface this phase).
- [x] `is_player` behaviour is never engine-generated — the human supplies the prose.
- [x] Off-turn / failed writes leave the save exactly unchanged (transaction rollback).

## Out of scope

Sourced delivery + the two-layer record (Phase 2), the bounded context window + scene summary (S-5.2.1 remainder), resume anchor (S-5.3.1), `elapsed_bucket` decay (Phase 5), boundary subsystems (Phase 4).
