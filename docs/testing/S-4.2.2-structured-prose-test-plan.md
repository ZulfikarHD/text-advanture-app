# S-4.2.1 / S-4.2.2 — Narrator Structured Prose Call Test Plan

> **Feature:** [../features/narrator/S-4.2.2-structured-prose-output.md](../features/narrator/S-4.2.2-structured-prose-output.md) · **Last Updated:** 2026-06-08

## Scope

Covers one narrator turn end-to-end through the `narrate` endpoint: a validated structured payload advances the loop spine by its handoff; the opening turn enters the loop first; and the S-4.2.2 safety guarantee — malformed output (here an out-of-vocabulary handoff) is retried to the bound, recorded as a `Failed` call, surfaced as an error toast, and **never** advances the loop. Also covers off-turn rejection (no call spent), owner-scoping, the auth gate, and the validator's new `enum`-membership check at the transport level. Does **not** cover persisting prose into the `events` scene log (S-5.2.1), `elapsed_bucket` consumption (Phase 5), the resume anchor (S-5.3.1), or the Play reader / advance control (S-5.4.1).

## Preconditions / fixtures

- Seed the `prompt_blocks` registry (`PromptBlockSeeder`) and the global `model_profiles` (`ModelProfileSeeder`, so `narrator_prose` resolves).
- A save (`PlaySession`) at `state_node = narrator_turn` (or `session_start` for the opening-turn case), positioned at a hand-authored `chapter 1 → scene → beat`: scene `pov_mode = third_limited`, `pov_anchor = luna`, `tone = tense`, `present_characters = [luna, player]`; beat `goal = "Luna and the player meet"`; characters `luna` (with appearance) + `player` with chapter-1 cards.
- The owner has a stored `provider_credentials` key (`ProviderCredentialService::store`, under auth).
- `Http::fake` returns the OpenRouter chat response (`choices[0].message.content` = JSON `prose · handoff · elapsed_bucket`); `Http::preventStrayRequests()`. Malformed cases set `services.openrouter.max_retries = 1` and `Sleep::fake()` so backoff is instant.
- Backed by `tests/Feature/Narrator/NarratorTurnTest.php` + `tests/Feature/Llm/StructuredOutputRetryTest.php` (`RefreshDatabase`, factories).

## Safety assertions

- [x] The loop is **never advanced** on a malformed/failed call — the LLM call runs before any transition, so a failure leaves `state_node` + position exactly as they were (cases 6–8).
- [x] An out-of-vocabulary `handoff` is treated as **malformed**, not routed — the narrowed enum (`player_moment | beat_complete`) keeps the model from reaching the unwired `npc_moment` branch (cases 6, 12).
- [x] A failed turn is **recorded** (`Failed` `llm_calls` row) and **surfaced** (error toast), so neither the audit log nor the player silently loses the failure (cases 6, 8).
- [x] Narrating off-turn spends **no** LLM call (the guard fails closed before resolution, case 9).
- [x] The endpoint is owner-isolated (404, case 10) and auth-gated (login, case 11).
