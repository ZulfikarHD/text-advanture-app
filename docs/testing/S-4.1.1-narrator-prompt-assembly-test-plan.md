# S-4.1.1 — Narrator Prompt Assembly Test Plan

> **Feature:** [../features/narrator/S-4.1.1-narrator-prompt-assembly.md](../features/narrator/S-4.1.1-narrator-prompt-assembly.md) · **Last Updated:** 2026-06-08

## Scope

Covers registry-driven assembly of the narrator prompt: which blocks are lit and in what order, that deferred blocks are absent with no filler, that selection/order are read from the registry rows (not code), the conditional `RESUME_ANCHOR`/`LOREBOOK` blocks, the reveal-chapter gate, the per-block bodies, and the system/user message split. Does **not** cover the LLM prose call or the structured handoff (S-4.2.1), the `MESH_AWARENESS`/`DIRECTOR_STATE` producers (Phase 4), or LLM-folding via `compile_instruction` (deferred).

## Preconditions / fixtures

- Seed the `prompt_blocks` registry (`PromptBlockSeeder`) — 16 rows, 7 narrator.
- A save (`PlaySession`) at `state_node = narrator_turn`, positioned at a hand-authored `chapter 1 → scene → beat`: scene `pov_mode = third_limited`, `pov_anchor = luna`, `tone = tense`, `present_characters = [luna, player]`; beat `goal = "Luna and the player meet"`.
- Two characters (`luna`, `player`) with chapter-1 cards (`luna` has an appearance; `player` has none).
- Optional: a `lorebook_entries` row (keyword `Luna`), and a `resume_anchor` payload on the save.
- Backed by `tests/Feature/Narrator/NarratorPromptAssemblyTest.php` (`RefreshDatabase`, factories; assembler resolved from the container).

## Safety assertions

- [x] No `true_state` or hidden character interiority is read — the assembler sources only authoring-realm scene/beat/card/lorebook + the save's own loop state (cases 10–12).
- [x] The narrator `LOREBOOK` honours the minimum-reveal-chapter gate, so a not-yet-revealed fact never enters the prompt (case 9).
- [x] No block with an unbuilt producer is fabricated — absence is structural, not filler (case 2).

## Out of scope

- The LLM prose call, structured output, and handoff routing (S-4.2.1).
- The `MESH_AWARENESS` (mesh / hedged-attribution) and `DIRECTOR_STATE` (engine clock) producers (Phase 4).
- LLM-folding of blocks via `compile_instruction` (the `compiler` role) — deferred (PH-39).
